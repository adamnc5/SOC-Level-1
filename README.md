# SOC Level 1 — My Learning Journey

I'm a cybersecurity student working through TryHackMe's SOC Level 1 pathway. This repository summarizes what I've learned through the lessons and hands-on labs.

My goal is to understand how security analysts investigate suspicious activity, connect evidence, and explain their findings.

## What I've Learned

### SOC Operations
How a Security Operations Center works, how analysts prioritize alerts, distinguish true and false positives, and document findings for escalation.

### Security Tools
The roles of SIEM, EDR, and SOAR. I explored log analysis with Splunk and Elastic, endpoint monitoring, and automated investigation workflows.

### Cyber Defence Frameworks
How the Pyramid of Pain, Cyber Kill Chain, Unified Kill Chain, and MITRE ATT&CK help explain attacker behavior and guide detection.

### Phishing Analysis
How to examine email headers, suspicious links, and attachments. I also studied email protection mechanisms such as SPF, DKIM, and DMARC.

### Network Traffic Analysis
How to inspect packet captures with Wireshark and NetworkMiner, filter traffic, and recognize patterns such as scanning and suspicious communications.

### Intrusion Detection with Snort
How to analyze captured traffic, understand Snort alerts, write basic detection rules, and troubleshoot rule syntax.

### Network and Web Attacks
How defenders detect network discovery, data exfiltration, man-in-the-middle attacks, web attacks, web shells, and denial-of-service activity.

### Windows Security Monitoring
How to use Windows event logs, Sysmon, and PowerShell logs to investigate authentication, suspicious processes, and persistence.

### Linux Security Monitoring
How to examine Linux authentication and system logs, use auditd evidence, and investigate suspicious SSH access or exposed services.

### Malware and Threat Intelligence
How to classify malware, understand basic static and dynamic analysis, recognize abuse of legitimate tools, and enrich files, hashes, IP addresses, and domains.

## What I'm Practicing Next

- Writing and explaining Snort rules.
- Connecting related events in Windows and Linux logs.
- Writing short investigation reports supported by evidence.

These notes summarize my lab learning. I'll add personal investigation examples and screenshots as I revisit the exercises.
